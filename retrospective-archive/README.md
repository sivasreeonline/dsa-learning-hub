# Retrospective DSA Practice Archive — 2026

## About

This directory organizes Data Structures and Algorithms (DSA)
practice materials by month for February–September 2026.

## Important Note

This is a retrospective archive. The month in a folder represents
the period the material relates to, not necessarily the date it
was added to this Git repository.

Original creation or practice dates are included only when known
or supported by available records.

## Monthly Archive

| Month | Focus |
|---|---|
| February 2026 | DSA fundamentals and problem-solving |
| March 2026 | Arrays, strings, and searching |
| April 2026 | Recursion and sorting |
| May 2026 | Linked lists, stacks, and queues |
| June 2026 | Trees, graphs, and core data structures |
| July 2026 | Greedy algorithms and dynamic programming |
| August 2026 | Dynamic programming and interview practice |
| September 2026 | LeetCode solutions and learning guides |

These are organizational categories, not claims that every topic
was practiced during the corresponding month.

## Problem Documentation Template

For each problem, document:

1. Problem name and platform
2. Problem statement or link
3. Approach and intuition
4. Java implementation
5. Dry run
6. Time complexity
7. Space complexity
8. Actual practice date, if known
9. Archive entry date
