## How to Use Each Problem Folder

Open a problem folder to find the available files:

- `LEARNING_GUIDE.md` — learning notes and explanation
- `Main.java` — executable Java program, where available
- Problem-specific Java solution
- `README.md` — problem documentation

## Practice Date Policy

Add an original practice date only when supported by a reliable
record, such as a dated notebook, submission, or contemporaneous
learning log.

The date this index is added to Git is not the original practice
date of the problems listed here.
