# DSA Learning Hub

A student-friendly DSA learning hub with starter code, problem-solving strategies, clear solutions, and interview-focused explanations.

## Repository Structure

- **LeetCode Problems:** Java solutions, executable `Main.java` files, and learning guides.
- **Retrospective Practice Archive:** A month-wise archive of DSA learning materials, with original practice dates recorded only when known.

## Retrospective Archive

Explore the [2026 Retrospective DSA Practice Archive](retrospective-archive/README.md).

The archive organizes learning materials by month. The month represents the period the material relates to, not necessarily the date it was committed to this repository.

## Learning Approach

Each problem is intended to support learning through:
- Problem understanding and intuition
- Java implementation
- Dry runs and examples
- Time and space complexity analysis
